# ApplyFlow: Job Application Management Platform

ApplyFlow is a MERN-stack web application designed to help job seekers organize and track their job applications throughout the recruitment process.

The platform will allow users to:
- Create an account and securely log in.
- Add, edit, delete, and manage job applications.
- Track application progress through an interactive Kanban board.
- Schedule and manage interviews.
- View application statistics and progress through a personalized dashboard.
- Search, filter, and sort applications.

**Technology Stack:**
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Authentication: JWT and bcrypt

**Project Type:** MERN Stack 'Lab Phase'
